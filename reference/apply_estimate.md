# Recalibrate a model at an estimate's point values

Recalibrate a model at an estimate's point values

## Usage

``` r
apply_estimate(est, type = "mean")
```

## Arguments

- est:

  A `qpm_estimate`.

- type:

  Passed to
  [`coef.qpm_estimate()`](https://mustapha-wasseja.github.io/qpmR/reference/qpm_estimate.md).

## Value

The estimation model recalibrated at the chosen point estimate
(structural parameters and shock sds).
